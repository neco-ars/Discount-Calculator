# Калькулятор скидки

Простое приложение на Python + tkinter для расчёта скидки
по возрасту и активности пользователя.

## Правила скидки

| Условие                | Множитель |
|------------------------|-----------|
| Возраст меньше 18 лет  | × 0.9     |
| Пользователь неактивен | × 0.8     |

Скидки суммируются: несовершеннолетний неактивный пользователь получает множитель 0.72 (скидка 28%).

## Запуск

Нужен Python 3 (tkinter входит в стандартную поставку).

```
python discount_calculator.py
```
